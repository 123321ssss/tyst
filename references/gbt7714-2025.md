# GB/T 7714-2025 参考文献著录规则速查（太原科技大学 2026 规范）

## 1. 排版格式要求

- **顺序编码制**：按正文引用出现先后顺序以 `[1]`、`[2]`… 编排，正文中以上标 `^[1]` 标注（Times New Roman 小四）。
- **条文格式**：宋体 / Times New Roman，**五号（10.5pt）**，两端对齐，**悬挂缩进 1.5 字符**，段前 0 行、段后 0 行，**固定值 16 磅**。
- **编号空格**：`[序号]` 与第一作者姓名之间空 **1 个半角空格**（如 `[1] 张伯伟. ...`）。
- **篇数底线**：硕士一般不少于 **30 篇**（含 6～10 篇以上外文文献）；博士一般不少于 **80 篇**（外文不少于总数的 1/2）。

## 2. 文献类型与载体标识代码

- **文献类型**：图书 `M`、期刊 `J`、报纸 `N`、会议录 `C`、学位论文 `D`、报告 `R`、标准 `S`、专利 `P`、网站/网页 `EB`、档案 `A`、地图 `CM`、数据集 `DS`、预印本 `PP`、汇编 `G`、计算机程序 `CP`、数据库 `DB`、其他 `Z`。
- **电子载体**：磁带 `MT`、磁盘 `DK`、光盘 `CD`、联机网络 `OL`、缩微资料 `MM`（联机资源写作 `[J/OL]`、`[D/OL]`、`[EB/OL]`、`[DS/OL]`、`[PP/OL]` 等）。

## 3. 主要文献类型标准著录格式（GB/T 7714-2025）

1. **图书 `[M]`**：
   `[序号] 主要责任者. 题名：其他题名信息[M]. 版本. 出版地：出版者，出版年：引文页码.`
   例：`[1] 张伯伟. 全唐五代诗格汇考[M]. 南京：江苏古籍出版社，2002：288.`
2. **期刊析出文献 `[J]`**：
   `[序号] 析出文献主要责任者. 题名[J]. 刊名，年，卷（期）：页码.`
   英文例：`[1] Dorsch R G, Häusler G, Herrmann J M. Laser triangulation: fundamental uncertainty in distance measurement[J]. Applied Optics, 1994, 33(7): 1306-1314.`
3. **会议录 `[C]`**：
   `[序号] 主要责任者. 题名[C]//会议名称，会议年份：引文页码.`
4. **学位论文 `[D]`**：
   `[序号] 主要责任者. 题名[D]. 学位授予单位所在地：学位授予单位，学位授予年：引文页码.`
   例：`[11] 王琦. 融合星载GNSS-R和SAR数据的高时空分辨率土壤湿度反演方法研究[D]. 武汉：武汉大学，2022：87.`
   （注：不得在学位授予单位后多余写出“博士学位论文”字样，标识 `[D]` 已标明学位论文类型。）
5. **报告 `[R]`**：
   `[序号] 主要责任者. 题名：报告编号[R/OL]. 发布日期：引文页码. 获取路径.`
6. **标准 `[S]`**：
   `[序号] 标准编号 标准名称[S].`
   例：`[15] GB/T 3792—2021 信息与文献 资源描述[S].`
7. **专利 `[P]`**：
   `[序号] 专利申请者/所有者. 题名：专利申请号[P]. 公告（公开）日期：引文页码.`
8. **网站/网页 `[EB/OL]`**：
   `[序号] 主要责任者. 题名[EB/OL]. （创建或修改日期）[引用日期]. 获取和访问路径.`
9. **数据集 `[DS/OL]` 与预印本 `[PP/OL]`**（2025 版新增重点）：
   - 数据集：`[序号] 主要责任者. 题名[DS/OL]. 版本. 发布平台（发布日期）[引用日期]. 获取路径. 永久标识符.`
   - 预印本：`[序号] 主要责任者. 题名[PP/OL]. 出版平台（创建日期）[引用日期]. 获取路径. 永久标识符.`

## 4. 学术成果列表格式差异（与参考文献的区别）

- **攻读学位期间取得的学术成果**要求列出**所有作者（全名）**，不得用“等”省略；
- 论文条目末尾标注收录情况与对应章节，如 `（SCI 一区，对应论文第 3 章）`；
- 按类别分组：`一、学术论文`、`二、国家发明专利`、`三、科研项目`、`四、其他`（宋体小四加粗）。
