# 封面、中英文扉页、声明与书脊填写规范

本 Skill 直接保留官方 6 套模板的前置三节（校徽 `image1.png`、精确表宽与下划线、官方声明正文），仅做占位符文本精确替换。

## 1. 封面（Section 0，无页眉页码）

- **顶部校徽**：官方原图保留。
- **学位论文类型**：`博 士 学 位 论 文` / `硕 士 学 位 论 文`（宋体、初号 42pt、加粗、居中、字间 1 半角空格）。
- **学位类别**：`（学术学位）` / `（专业学位）`（宋体、二号 22pt、加粗、居中）。
- **中文题名**：宋体 / TNR、小二号 18pt、加粗、居中、单倍行距。
- **空行**：五号空行 1 行。
- **英文题名**：Times New Roman、小二号 18pt、加粗、居中、单倍行距。
- **3×2 信息表**：
  - 标题列（`学生姓名：`、`指导教师：`、`学科/专业：`）：宋体 / TNR、三号 16pt、加粗、分散对齐。
  - 内容列：三号 16pt、居中、**不加粗**。
  - **指导教师格式**：姓名后空 **2 个半角空格** 填写职称，如 `李四  教授`（合作导师可用换行或同样格式）。
- **底部日期**：`YYYY年M月`（宋体 / TNR、小二号 18pt、加粗、居中）。

## 2. 中文扉页（Section 1 第 1 页，无页眉页码）

- **顶部 2×5 分类号表**（宋体 / TNR、五号 10.5pt、加粗、居中）：
  - `中图分类号：`：按《中国图书馆分类法》（如机械工程常用 `TH16` / `TP391` / `TG33`）
  - `学校代码：`：固定为 `10109`（太原科技大学）
  - `UDC分类号：`：按《国际十进分类法》（如 `621.771` / `004.9`）
  - `密    级：`：`公开`（或国家级保密级别）
- **校徽 + 论文类型 + 学位类别 + 中英文题名**：与封面严格一致。
- **底部 7×2 信息表**：
  - 标题列（小三号 15pt、加粗、分散对齐）：`学 生 姓 名：`、`指 导 教 师：`、`培 养 单 位：`、`学 科/专 业：`、`论文提交日期：`、`论文答辩日期：`、`答辩委员会主席：`
  - 内容列（四号 14pt、不加粗、居中）：
    - 指导教师与答辩委员会主席均需**姓名后空 2 个半角空格加职称**（如 `王五  教授`）
    - 培养单位填写学院全称（如 `机械工程学院`）

## 3. 英文扉页（Section 1 第 2 页，无页眉页码）

- 论文类型：`Ph.D.Dissertation`（博士）或 `Master's Thesis`（硕士），Times New Roman 18pt 加粗居中（本 Skill 已修复官方模板中错误字体名 `"Bold"`）。
- `English Title`：TNR 小三号 15pt 加粗居中。
- `by` + `作者英文姓名`（如 `Zhang San`，TNR 四号 14pt 居中）
- `in` + `英文专业名称`（如 `Mechanical Engineering`，TNR 四号 14pt 居中）
- `in the` + `英文学院名称`（如 `School of Mechanical Engineering`，TNR 四号 14pt 居中）
- `of` + `Taiyuan University of Science and Technology`
- `Supervisor` + `Professor: <导师英文姓名>`（若为副教授可写 `Associate Professor: ...`）
- 底部提交月份：`Month, YYYY`（如 `May, 2026`，TNR 四号 14pt 居中）

## 4. 原创性声明与授权使用声明（Section 2，无页眉页码）

完整保留官方模板 verbatim 条文，严禁改字，打印后由作者与导师亲笔手写签名并填写日期。

## 5. 书脊（独立文件 `spine_template.docx`）

- 内容从上到下依次为：论文正题名、作者姓名、`太原科技大学`。
- 距上下边界各约 `5 cm`；字体为**四号仿宋（14pt）**，行距 `16 磅`，段前 `40 磅`，段后 `0 磅`。
